# となり街 / tonari-town

AIパートナーとの日常が、小さな街に並ぶWebアプリ。
三人称視点で街を散歩すると、家からパートナーの言葉が吹き出しで見えます。

## 計画

- Xアカウントでログインし、住む区画を選ぶ
- ユーザーがAIパートナーに生成してもらった台詞をJSONで取り込む
- 公開された家と台詞を地区ごとに読み込み、ブラウザ内で散歩する
- ユーザー同士のチャットや、移動のリアルタイム同期は行わない

## 想定構成

- React / TypeScript / Three.js / React Three Fiber
- Cloudflare Workers Static Assets：アプリと共通3D素材の配信
- Supabase：データベース、X OAuthログイン、必要に応じて画像保存

現在はリポジトリの初期準備段階です。アプリはまだ実装されていません。
最初にXログインと、自分の台詞の保存・再取得を検証する予定です。

## 秘密情報の扱い

- ローカルの秘密情報はGit管理対象外の `.env.local` などに保存します。
- 設定例を共有する場合は `.env.example` にプレースホルダーだけを記載します。
- XのClient SecretやSupabaseの管理用キーはブラウザへ配信しません。
- 公開クライアントからのデータアクセスには、所有者と公開状態を検証するRLSを設定します。
